# Vayu Evolution Evidence — 2026-08-22

## Domain

Attention / salience control.

## Observed gap

The measured baseline before this increment was perception `0.15`, world model `0.18`, attention `0.20`. Perception is numerically weakest, but multimodal inputs need a bounded focus-selection layer before they are allowed into the cognitive loop. Without it, future voice/vision/device streams could compete directly with user intent and planning without a stable interruption policy.

## Hypothesis

A pure, deterministic attention controller that ranks bounded stimuli by importance, urgency, novelty and confidence will provide a safer prerequisite for multimodal perception and reduce the risk of noisy or low-confidence events hijacking Vayu's focus.

## Implementation

- Added `app/attention.py` with typed stimuli, deterministic salience scoring and bounded ranking.
- Added interruption policy requiring both absolute salience and a margin over current focus.
- Added a narrow safety override requiring high urgency and high confidence.
- Added deterministic tie-breaking and duplicate-ID/batch-size validation.
- Kept the subsystem pure: no model calls, persistence, tools, networks or execution authority.
- Added regression tests covering ranking, uncertain novelty, ordinary interruption suppression, safety interruption, low-confidence safety rejection and resource bounds.

## Evidence and score change

Attention baseline: `0.20 -> 0.38`.

The increase is intentionally conservative. A dedicated tested controller now exists, but it is not yet connected to live perception/command processing and does not maintain durable focus context. No other cognitive domain score was increased.

## Safety / regression gate

The controller cannot invoke executors or mutate action approval state. Salience is advisory only. It preserves the existing rule that attention does not imply authority. Resource use is bounded to 64 stimuli per ranking call and the implementation is deterministic and network-free.

## Rollback point

Known-good base before this increment: `a7c410634481abc394f2307031316f065ee77bde`.

## Lesson

The weakest measured domain is not always the correct immediate implementation target. Prerequisite relationships should influence evolution sequencing, but they must not be used to inflate the weaker domain's score. Perception therefore remains at `0.15`.

## Next proposed target

Build a bounded perception event contract and ingestion boundary for text/voice/vision/browser/device observations. Perception should emit normalized stimuli into the attention controller, never directly into executors. A failure path must prove malformed/untrusted perception data cannot obtain action authority.
